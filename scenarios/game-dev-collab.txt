# Block Drop - Game Design Document

## Core Concept
A Tetris-style falling block puzzle game. Pieces fall from the top, player rotates and moves them to complete horizontal lines.

## Game Mechanics

### Grid
- 10 columns x 20 rows
- Each cell is either empty (0) or filled (1)
- Simple 2D array: `grid[y][x]`

### Pieces (Tetrominoes)
- 7 classic shapes: I, O, T, S, Z, J, L
- Each piece is a 4x4 array of 0s and 1s
- Rotation: transpose + reverse rows

### Controls
- Left/Right Arrow: Move piece
- Up Arrow: Rotate
- Down Arrow: Soft drop (faster fall)
- Space: Hard drop (instant)

### Core Loop
1. Spawn piece at top center
2. Piece falls one row per tick (speed increases with level)
3. Player can move/rotate while falling
4. When piece lands: lock it, check for complete lines
5. Clear complete lines, add score
6. Spawn next piece
7. Game over if new piece overlaps existing blocks

### Scoring
- 1 line: 100 points
- 2 lines: 300 points
- 3 lines: 500 points
- 4 lines (Tetris!): 800 points
- Level up every 10 lines

### Key Functions

Rotation:
```javascript
function rotate(piece) {
  return piece[0].map((_, i) => piece.map(row => row[i]).reverse());
}
```

Collision Check:
```javascript
function canMove(piece, offsetX, offsetY) {
  for (let y = 0; y < piece.length; y++) {
    for (let x = 0; x < piece[y].length; x++) {
      if (piece[y][x]) {
        let newX = pieceX + x + offsetX;
        let newY = pieceY + y + offsetY;
        if (newX < 0 || newX >= COLS || newY >= ROWS) return false;
        if (newY >= 0 && grid[newY][newX]) return false;
      }
    }
  }
  return true;
}
```

Line Clear:
```javascript
function clearLines() {
  let linesCleared = 0;
  for (let y = ROWS - 1; y >= 0; y--) {
    if (grid[y].every(cell => cell !== 0)) {
      grid.splice(y, 1);
      grid.unshift(new Array(COLS).fill(0));
      linesCleared++;
      y++;
    }
  }
  return linesCleared;
}
```

### Visual Design
- Dark background (#1a1a2e)
- Colorful pieces (classic Tetris colors)
- Ghost piece showing where current piece will land
- Next piece preview box
- Score/Level/Lines display
